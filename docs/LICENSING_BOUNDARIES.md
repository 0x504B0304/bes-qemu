# 许可边界与剩余线索

QEMU 组合程序及派生实现、补丁、构建输入、启动解析器和原地执行的 MMIO/IRQ/DMA/GPU/存储模型保持公开。分发时应按实际适用 GPL 条款提供完整对应源码；不能将必要头文件、生成器、配置或链接代码藏入商品包。仅将文件移到另一个目录、进程或格式不构成闭源许可依据。

Studio 的 Web、宿主工具及编排在独立进程运行。它们在技术上可独立部署，但有外部贡献尚待逐文件确认，故不一概声明可闭源。原版权、来源和许可证继续有效。此前在迁移中加入的 blanket MIT/proprietary/GPL 重授权判断已撤回；LICENSES 内文本本身不授予未知权利。

独立型号包和服务可以约定商业授权。该约束不限制用户依据 GPL 修改、编译或使用核心，也无法阻止第三方自行适配同一设备。

仍可推断设备的线索包括：SoC/IP 名称、内存和寄存器地址、IRQ、驱动行为、器件支持范围、固件兼容逻辑、测试中的数字常量、协议名称、代码风格以及公开历史。它们属于真实实现、测试证据或来源声明，不能靠删除必要源码消除。公开互操作协议保留厂商名称，但当前核心不再提供商品名称与配置组合的注册表。

独立的 `miband-public-review` 保留原始源码、来源说明及待确认部分的当前公开副本。这些材料仍包含已公开的商品映射；在权利明确之前不得将其标为保密或只向付费用户提供。Git 历史未清理，旧公开信息无法撤销。

商业发布前必须：确认外部贡献的原许可证与重授权权利；审查补丁/注入/协议代码的来源和派生关系；保留 Golden Layout 等依赖通知并审核本地修改；取得固件、字体、表盘和快应用等资产的分发许可；选定实际 GPL 对应源码交付方式。本次未代替权利人作授权。bes-qemu 与 miband-studio 已创建为私有仓库供内部构建；尚未公开发布仓库或商业制品。原仓库历史保持不变，新仓库从白名单快照建立新历史。
